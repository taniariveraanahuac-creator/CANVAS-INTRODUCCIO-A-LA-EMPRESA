# Canvas Lab · ADM1401 Introducción a la Empresa

Laboratorio interactivo para aprender y aplicar el **Modelo Canvas** (Temas 9 y 10) con casos reales
de la Península de Yucatán: PAMASUR, El Yucateco, Sal Sol, Kekén, miel orgánica (EDUCE),
Ingenio San Rafael de Pucté, Chicza, Sargablock y Community Tours Sian Ka'an.

Profesora: Tania Rivera Lozano · Universidad Anáhuac Cancún · Escuela Internacional de Negocios.

Es una página estática de un solo archivo (`index.html`), sin servidor.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en https://github.com/new (por ejemplo `Canvas-Lab`).
2. Sube `index.html`, `README.md` y `.nojekyll`.
3. En **Settings → Pages**: *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
4. Tu liga será `https://taniariveraanahuac-creator.github.io/Canvas-Lab/`.

## Cómo se guarda
- En GitHub Pages el avance se guarda **en el navegador de cada dispositivo** (`localStorage`).
- Para juntar el trabajo: cada equipo usa **Reporte → Exportar respaldo** y la docente
  lo carga en **Docente → Importar respaldo**.
- Clave del panel docente: se define en `TEACHER_PIN` dentro de `index.html`.

## Notas
- Un repositorio público deja ver `index.html`, que incluye la lista de nombres de los alumnos
  y la clave docente.
